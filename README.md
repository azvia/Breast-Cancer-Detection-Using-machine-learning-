# Breast Cancer Detection Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning classification algorithms to predict whether a breast tumour is **Benign (B)** or **Malignant (M)** based on features extracted from breast cell nuclei.

The project uses the **Wisconsin Diagnostic Breast Cancer (WDBC) Dataset** and compares multiple machine learning models to identify the best-performing classifier.

## 🎯 Objectives

- Analyze and preprocess the breast cancer dataset.
- Train machine learning models for tumour classification.
- Compare different classification algorithms.
- Evaluate model performance using standard metrics.
- Identify important features influencing predictions.

## 📊 Dataset

The project uses the Wisconsin Diagnostic Breast Cancer (WDBC) dataset.

- **Total Instances:** 569
- **Features:** 30 numerical features
- **Target Classes:**
  - Benign (B)
  - Malignant (M)
- **Missing Values:** None

The features are calculated from digitized images of Fine Needle Aspirate (FNA) samples and describe characteristics of cell nuclei.
